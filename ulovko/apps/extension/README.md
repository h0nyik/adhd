# Rozšíření prohlížečů

**WXT**, jeden kód pro Chrome, Edge, Operu, Firefox a Safari.

Pravidla, která musí platit od prvního řádku:
- Affiliate odkaz jen po akci uživatele a s jasným přínosem pro něj, program popsaný
  v obchodě i v UI (pravidla Chrome Web Store od roku 2025).
- Jen volitelná oprávnění pro podporovaná tržiště a `activeTab`.
- Žádné cookies ani osobní data ze stránky. Cenu z otevřené stránky odeslat jen se souhlasem.

Barvy: `design/tokens/build/tokens.css`.
