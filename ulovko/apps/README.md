# Aplikace

Každá platforma má nativní UI. Sdílí se logika (`shared/core`), design tokeny
(`design/tokens`) a backend (`services/api`).

| Složka | Technologie | Stav |
|---|---|---|
| [apple/](apple/README.md) | SwiftUI: iOS, iPadOS, macOS + Safari rozšíření | Vygenerované tokeny, projekt založí první iOS vývojář |
| [android/](android/README.md) | Kotlin + Jetpack Compose | Plán, čeká na Android SDK v prostředí |
| [windows/](windows/README.md) | WinUI 3 (fáze 2) | Plán |
| [web/](web/README.md) | SSR web + PWA | Plán |
| [extension/](extension/README.md) | WXT: Chrome, Edge, Opera, Firefox, Safari | Plán |
